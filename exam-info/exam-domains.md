# 🧩 AWS SAA-C03 Exam Domains

The exam tests knowledge across four main domains:

---

## 1. 🛡️ Design Secure Architectures (30%)

- IAM users, groups, roles, and policies
- KMS and encryption at rest/in transit
- Security groups vs NACLs
- Shared responsibility model
- AWS WAF, AWS Shield, Secrets Manager

---

## 2. 🔁 Design Resilient Architectures (26%)

- Fault-tolerant system design
- Multi-AZ & Multi-Region deployments
- High availability using ELB and Auto Scaling
- Backup and disaster recovery strategies

---

## 3. ⚡ Design High-Performing Architectures (24%)

- Selecting the right compute, database, and storage options
- Read/write performance tuning
- Caching with ElastiCache and CloudFront
- Optimizing throughput and latency

---

## 4. 💸 Design Cost-Optimized Architectures (20%)

- Right-sizing instances
- Using Spot, Reserved, and Savings Plans
- S3 storage classes and lifecycle rules
- Billing tools (Cost Explorer, Trusted Advisor)

---

## 💡 Tip

Focus on **scenarios** involving trade-offs: cost vs performance, security vs usability, or availability vs fault tolerance.
