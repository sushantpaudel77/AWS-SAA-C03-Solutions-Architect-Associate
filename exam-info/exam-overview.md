# 📝 AWS SAA-C03 Exam Overview

## 📘 Exam Summary

- **Exam Name**: AWS Certified Solutions Architect – Associate
- **Exam Code**: SAA-C03
- **Level**: Associate
- **Duration**: 130 minutes
- **Questions**: 65 (Multiple choice / multiple response)
- **Passing Score**: ~720/1000 (scaled)
- **Cost**: $150 USD
- **Delivery Method**: Pearson VUE or PSI (online or testing center)
- **Languages**: English, Japanese, Korean, Simplified Chinese

## 👤 Target Audience

- 1+ years of experience designing cloud architectures on AWS
- Hands-on experience with compute, storage, networking, and database services
- Familiarity with AWS Well-Architected Framework
- Basic knowledge of best practices for security and cost optimization

## 🎓 Certification Validity

- Valid for 3 years
- Renewal requires retaking the exam or upgrading to a higher-level certification

## 📦 Exam Format

- 65 questions
- Multiple choice & multiple response
- Scenario-based, real-world architecture situations
